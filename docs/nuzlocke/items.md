# 🧗 Items

A small toolkit for a run on the road. Right now that's the **Escape Rope** — a one-tap ticket back
to town.

## 🧗 Escape Rope

Use it and you're whisked to the **nearest known town** on
[Routes'](../routes/index.md) network — and because every **activated waystone registers as a town**,
it works whether or not you run the Waystones mod.

- **Where it sends you** — the closest discovered city / town, landing on a safe, dry column (the
  same spot-finder that places a new world's spawn).
- **Restrictions** — Overworld only, **never mid-battle**, with a short **10-second cooldown**.
- **Cost** — consumes one rope per use (free in creative). One craft makes **two**.

!!! tip
    No known town yet? The rope politely refuses and tells you so — go discover a village or
    activate a waystone first.

!!! warning "No roping out of a battle"
    The rope will not fire while you are in a Pokémon battle. On a Nuzlocke run that is the whole
    point: a fight you started is a fight you finish.
