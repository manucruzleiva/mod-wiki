# FAQ

??? question "Does re-rolling despawn my own Pokémon?"
    No. The despawn step skips any Pokémon that has an **owner** (yours or another player's) and any
    tethered/busy Pokémon. Only **wild** Pokémon in range are cleared.

??? question "Why won't my table place?"
    The table is a **3×2 multiblock** and deploys **in front of you**. All six cells need to be free.
    The **Diving** table additionally requires being **underwater**.

??? question "I broke one block and the whole table disappeared."
    That's intended — a Picnic Table is a single multiblock structure. Breaking any cell breaks the
    whole table and returns the item. (Place tables so their footprints don't overlap.)

??? question "The re-roll says I'm out of fuel."
    Basic and Camping tables consume **bread** per re-roll. Put bread in the fuel slot or place a
    **[Picnic Basket](interactions-and-items.md#picnic-baskets)** with bread nearby. Glamping and
    Diving are free.

??? question "How do I increase shiny odds?"
    **Sit on the benches** — each occupied seat adds to the [Shiny Aura](shiny-aura.md), which boosts
    your next re-roll. Bring friends for a bigger bonus. It can be tuned or disabled in config.

??? question "The Battle Seeker isn't doing anything."
    It only works in a **Glamping** table's slot, and it needs **Radical Cobblemon Trainers (RCT)**
    installed to spawn the trainer. See [Battle Seeker](battle-seeker.md).

??? question "Where do I find the Battle Seeker?"
    It has **no recipe** — it's a **rare chest loot** item. Keep looting structures.

??? question "Does this work on NeoForge?"
    **Yes!** Since **1.25.0**, Cobblemon Picnic ships for both **Fabric** and **NeoForge** (Minecraft
    1.21.1) with the same features on each. Grab the NeoForge build from
    [Modrinth](https://modrinth.com/mod/cobblemon-picnic) or CurseForge — it needs **Architectury API**
    + **Kotlin for Forge**.

??? question "Found a bug or have an idea?"
    Post it in the community **Discord**'s **#bugs** or **#features** channels — new posts (with their
    text and attachments) are picked up automatically and filed into the project's issue tracker, and
    you'll get a reply in your thread when a fix ships.
