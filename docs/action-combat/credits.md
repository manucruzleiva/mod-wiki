# Community Credits

Action Combat is built on the work of others:

- **Cobblemon**, whose Pokémon, battles and data every fight comes from.
- **Pokémon Showdown**, whose move, ability and item data seeds every real-time definition.
- **Cobblemon: Mega Showdown**, which owns the gimmicks' items, forms and visuals.
- **PokeBelt**, which carries the balls thrown mid-fight.
- **Radical Cobblemon Trainers**, whose trainers, series and level caps a real-time win still counts
  toward.

Found a bug or have an idea? Post it in the [Discord](https://discord.gg/SwcwXcCN4k).
