# Troubleshooting

Common surprises, what causes them, and what to do. If yours is not here, post it in the
[Discord](https://discord.gg/SwcwXcCN4k): it files the ticket for you.

## Nothing changed on my Pokémon

The mod only touches a Pokémon that is **31 in all six IVs**. Everything below that is plain
Cobblemon. Breed, catch or raise it there with Bottle Caps; see
[Which Pokémon it touches](getting-started.md#which-pokemon-it-touches).

## I keep running out of experience for training

Training is paid with **your** experience, and vanilla only pays experience for defeating mobs.
[Cobblemon: PlayerXP](https://modrinth.com/mod/cobblemon-playerxp) pays you for the battles your
Pokémon win. See [Training Costs](training-costs.md).

## My settings screen changes do nothing on a server

While you are connected to a server, your game uses the server's values, whatever your own file says.
The screen always edits **your own** file, which is what counts in single player and on a server you
host. See [The config screen](commands.md#the-config-screen).

## Does it run on Cobblemon 1.7.3?

No. Champions Training is built for Cobblemon **1.8** and 1.7.3 is not supported.
